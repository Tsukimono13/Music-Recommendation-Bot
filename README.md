# MusiGem

Telegram-бот для поиска музыкальных рекомендаций. Пользователь пишет запрос (артист, жанр, комбинация) — бот подбирает похожих исполнителей. Использует бэкенд с данными Last.fm, MusicBrainz, Spotify и моделью Gemma (Google) для разбора запроса.

---

## Возможности

| Кнопка / раздел | Описание |
|-----------------|----------|
| 🎸 Подобрать артистов | Один сценарий: ввод запроса (артист, теги или комбинация) → рекомендации |
| ⛏️ Копнуть глубже | После ответа: дополнительные артисты порциями по 9 (до 2 нажатий) |
| 🪪 О проекте | О боте и команде |
| ❓ FAQ | Ответы на частые вопросы, инструкция для артистов |
| 📻 Новости | Ссылка на канал [@MusiGemBotNews](https://t.me/MusiGemBotNews) |
| 🍩 Поддержать | Поддержка проекта (DonationAlerts, QR) |
| 📋 Отправить фидбэк | Идеи, багрепорты (в канал) |

Дополнительно: защита от флуда, ежедневный «факт дня» в 10:00 МСК.

---

## Стек

- **Node.js** + **TypeScript**, **tsx**
- **Telegraf** (Telegram Bot API)
- **node-cron** — планировщик фактов дня
- Внешний **бэкенд-API** для рекомендаций (`POST /api/music/recommend`)

---

## Переменные окружения

| Переменная | Описание |
|------------|----------|
| `TELEGRAM_BOT_TOKEN` или `BOT_TOKEN` | Токен бота от [@BotFather](https://t.me/BotFather) |
| `BACKEND_URL` | URL бэкенда с рекомендациями (обязательно) |
| `FEEDBACK_CHANNEL_ID` | ID канала для фидбэков (например `-1001234567890`) |
| `ADMIN_IDS` | ID админов через запятую (опционально, для админ-команд) |
| `WEBHOOK_URL` | Публичный URL сервиса для webhook. **Не задавать** — тогда бот работает в режиме long polling (удобно локально) |
| `PORT` | Порт HTTP-сервера (webhook, health, cron). По умолчанию `3000` |
| `HEALTH_PORT` | Отдельный порт для health (если нужен) |
| `CRON_SECRET` | Секрет для вызова крон-эндпоинта «факт дня» (`/cron/daily-fact?secret=...`) |

Пример: см. `.env.example`.

---

## Запуск

- **Локально (long polling):** задать `BOT_TOKEN`, `BACKEND_URL`, не задавать `WEBHOOK_URL` → `npm run dev` или `npm start`.
- **Деплой (webhook):** задать `WEBHOOK_URL` (полный URL сервиса, например на Render). Бот выставит webhook при старте.

---

## Скрипты

- `npm run dev` — запуск в режиме разработки (`tsx src/index.ts`)
- `npm start` — запуск для продакшена
- `npm run build` — без сборки (запуск через `tsx`)
